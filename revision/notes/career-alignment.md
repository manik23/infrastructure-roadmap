# Career Alignment Revision Notes

**Roadmap source:** [Target profile and scope](../../ROADMAP_2030_REVISED.md#1-target-profile-and-scope) and [Career validation](../../ROADMAP_2030_REVISED.md#career-validation-and-sustainable-execution)  
**Decision record:** [ADR 0001](../../docs/decisions/0001-career-alignment.md)

## Current direction

- Primary: distributed cloud infrastructure and storage/workload control planes.
- Complementary: AI workload/inference infrastructure only when role evidence,
  project value, and sustainable time support it.
- Foundation: Go, Linux, distributed-systems reasoning, Kubernetes control
  planes, correctness, performance, reliability, and production operations.
- Deferred by design: Rust, deep storage engines, streaming, eBPF, advanced
  networking, advanced AI serving, formal methods, and agentic operations.

## Evidence loop

Use the role scorecard and application tracker for repeated evidence, not
predictions. At the 120-day and quarterly reviews, assess actual role content,
interview feedback, project preference, on-call implications, and sustainable
time. Change direction only for repeated evidence.

## Guardrails

- Default study budget: six hours/week; eight-hour ceiling; three-to-four-hour
  busy-week fallback.
- Keep one progressive project: dispatcher, durable lifecycle service,
  Heterogeneous Workload Control Plane, production evidence, then optional AI
  extension.
- Do not add a framework, custom database, GPU stack, or language track merely
  because it is fashionable.
- Market/job examples in the imported refinement are dated inputs. They are
  not current hiring, compensation, or team-quality claims.

## What did not change

The Phase 1 through Phase 7 technical order, current prerequisite evidence,
worker-pool exercise, and Rust follow-up decision remain intact.
